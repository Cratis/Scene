# Scene — project context

Describing a user interface without describing a platform — the UI model of
the Cratis model-first layer (experimental). The object model and runtime for
Screenplay-based UIs: `Scene.Model` (platform-agnostic screens, layouts,
forms, contribution points, UI profiles and themes), `Scene.Engine`
(binding/resolution runtime), and the renderers. TypeScript.
